📘 Exam Dashboard Overview

Each exam card displays the exam title, description, duration, and creation date. Below each card, you’ll find four key action buttons:

  • Performance: View and analyze performance data for the selected exam.
  • Edit: Open the question set editor to modify or update existing exam questions and details. (If the exam is marked as “Live”, it becomes accessible to students immediately.)
  • Save For: Assign or save this exam for your students to attempt later.
  • Delete: Permanently remove the selected exam from your list — this action cannot be undone.
